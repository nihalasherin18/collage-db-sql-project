MySQL Student Database – SQL Practice

This project contains SQL queries written using MySQL to practice and understand fundamental SQL concepts. It uses a college database (college_db) containing student and enrollment information.

Topics Covered

SELECT statements

WHERE clause

AND, OR operators

NOT IN operator

BETWEEN operator

LIKE operator and pattern matching

NULL and IS NULL conditions

ORDER BY (ASC and DESC)

LIMIT clause

Filtering and sorting student records

Finding top-performing and youngest students

Objective

To improve SQL querying skills through practical exercises based on student and enrollment data.

Tools Used

MySQL

MySQL Workbench
